新旧菜单对应说明

以新版服务目录为主线，明确每个入口的名称、旧系统来源与交互去向。此页仅用于研发评审与交接，不属于产品功能菜单。

核对口径

新版路径以当前原型实际菜单为准；旧系统来源依据已确认调整、用户参考图与已保存的导航结构。“已确认”仅表示归属和名称已确认，不等同于线上权限、数据或接口已完成验证。

研发实现时，以“交互去向”为准：当前页原型可直接复刻；“独立页签提示”不在本原型内实现业务页；“运营后台保留”仅保留后台入口；“迁移到服务目录”代表后台入口已移除或不再作为主入口。

研发实现口径

当前页原型

服务目录内直接呈现本地页面与交互，如模型资源、IM 渠道、外部回调、系统管理等。

独立页签说明

技能构建需由用户确认后打开技能工厂；数据连接器、数据查询器、业务集成中心及效果评估只展示跳转提示。

运营后台保留

仅保留资源配置、文档与操作手册、Portal 管理、PivotAdmin 与系统配置。

后台入口已收敛

Worker 核心、三方纳管、AI 模型、渠道对接、技能广场，以及客户端设备、安全中心、审计中心不再出现在运营后台。

本次改版的关键调整

  • 技能构建对应技能工厂；点击后先展示说明，再由用户主动在新页签打开。技能管理承接原后台技能广场的管理功能；探索区 Skills 中心保留技能浏览入口。
  • 服务目录一级菜单调整为SOP 应用引擎、企业连接中枢、平台基础资源；平台基础资源仅保留模型管理、知识资产，模型日志不再放入“使用记录”。
  • 企业连接中枢分为业务连接与开放集成：前者承载数据连接、查询、业务集成，后者承载 MCP 工具、外部回调与智能体集成。
  • 三方 Claw、三方 Claude Code 与 A2A 中心归入企业连接中枢 → 开放集成 → 智能体集成；后台三方纳管分组已移除。
  • Worker 管理、看板归入运行实例；Worker 测试归入数字分身能力评估；Worker 价值归入业务价值分析。运营后台的 Worker 核心分组已整体删除。
  • 镜像、实例模板与实例在服务目录与后台共用原型；版本管理仅在服务目录展示，后台资源配置中已删除该入口。
  • 后台内容 & 工具仅保留文档、操作手册；团队模板、MCP 工具、Coding 技能、技能管理及能力命令库迁入服务目录。
  • 服务目录系统管理包含组织与成员、客户端管理、安全与审计；Portal 管理和平台级系统配置保留后台。客户端设备、安全中心、审计中心已从后台菜单删除。
